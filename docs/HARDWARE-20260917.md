## Install with XBMC and FTP

The new private test package is `.\dist\WOWX-hardware-20260917`.
The earlier September 16 package remains available unchanged.

1. Connect the Xbox by Ethernet. In your usual FTP client, connect to
   **192.168.50.85** with your existing Xbox FTP credentials.
2. Copy the **entire** PC folder
   `.\dist\WOWX-hardware-20260917\WOWX` to a **new** Xbox folder,
   such as `E:\Games\WOWX-20260917`. Use `F:\Games\WOWX-20260917` if that
   partition has more space. Allow **1.2 GiB free**.
3. Check that all **153 files / 1,060,926,510 bytes** transferred successfully.
   `default.xbe` and all assets belong directly together in that folder.
   All filenames fit FATX limits; the largest file is 170,923,304 bytes.
4. In **XBMC → File Manager**, open that folder and launch **default.xbe**.
   Connect the controller to port 1. The separate XISO is optional for xemu;
   it is not needed for this HDD installation.
5. The login address is prefilled as **192.168.50.156:3725** and the account
   as **WOWXTEST**. Enter the new password supplied in the conversation.
   D-pad to Password, press **A**, and use the on-screen keyboard: **A** enters,
   **X** erases, **Y** changes page, and **Start** finishes editing. Press
   **Start** again on the account form to connect.
6. Choose **WOWX Local**, then **Xboxdawn** for a first Northshire test.
   All five saved characters remain available; their progress was preserved.
7. Keep the PC awake while playing. Log out using **Start, then Y** and allow
   logout to finish before shutting down.

The optional ZIP contains the same `WOWX` folder and documentation. Extract it
on the PC before FTP transfer. Keep the existing dashboard and earlier game
folder intact. The game password is separate from the Xbox FTP password.

## Troubleshooting

- **Black screen / XBE won't launch:** check the FTP failed-transfer queue and
  that all 153 files are beside the XBE. Record console revision/mod/video mode
  and whether any text appeared.
- **Missing assets:** avoid nesting an extra `WOWX` folder below the XBE.
  The application expects its launch directory to be mapped to `D:\`.
- **Login timeout:** keep the PC awake, confirm its LAN address is still
  `192.168.50.156`, and run the server check above. A VPN must permit local LAN
  access. The game reads the Xbox's saved network configuration; working XBMC
  FTP alone does not prove the game's configuration.
- **Realm connection stalls:** the world port is **8086**, and the realm should
  advertise the PC LAN address, not xemu's `10.0.2.2`.
- **Password rejected:** use **WOWXTEST** and the new game password, not FTP
  credentials. The private PC credential store was updated consistently.
- **Unprepared area / incomplete model:** world and appearance coverage remain
  partial. Capture the character/position and message.

Settings and entropy consumption persist in `E:\WOWX`. Preserve them when
replacing the application folder. Entropy is finite; do not delete consumption
records to reuse an old pool. This build's automatic telemetry still targets
xemu's host address, so use on-screen diagnostics and PC server logs on hardware.

To end hardware networking later, log out and run
`.\scripts\hardware-network.ps1 -Mode Restore` in administrator PowerShell
from the repository root. It restores the old realm endpoint and removes only this test's
forwarding/firewall rules. Character progress and console files remain intact.
